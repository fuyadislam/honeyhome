01 / The bait

A fake camera. A fake router. A fake file server.

Each one looks like a cheap, unpatched device that network intruders love to find. They do nothing useful and hold nothing real. Their only job is to sit quietly and wait to be touched.

02 / The catch

The moment anyone knocks, HoneyHome is listening.

It fingerprints the device, spots password guessing and port scans, and names each move with the same MITRE ATT&CK codes a professional SOC uses. Then it speaks up through Alexa, in plain English.

03 / The evidence

Every event is sealed in a hash chain.

Each record locks in the one before it with a SHA-256 hash, like links in a chain. Change one old line and every link after it breaks.

Identify

Maker, device type, and whether it's hiding behind a random address.

Classify

Brute force, default logins, scans and path traversal, mapped to ATT&CK.

Report

A full incident report, written on command, ready to hand over.
